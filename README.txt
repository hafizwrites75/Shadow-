OPEN CITY — MERGED FINAL BUILD

This is the unified build of the Open City project: Steps 1–25 + the Final Build layer.
It is NOT a restart or a separate new game. The latest cumulative game code is used as the base and the final systems are integrated into it.

Preserved Step 1–25 systems include the city/open-world foundation, vehicles, combat, vehicle HUD/HP/fuel/boost, missions and mission board, mini-map, garage upgrades, day/night and weather, save/load/autosave, safehouse, and inventory/consumables.

Final layer includes: personal safehouse hub, owned red car and motorcycle, armory/weapon selection, outfit switching, phone/player hub menu, city-map overview, radio toggle, civilian ambience, fleet recall, and final save state.

Game style: original browser open-world game inspired by the feel of classic city crime games. No GTA copyrighted map/assets are included.

Run: open index.html in a modern browser with internet access (Three.js is loaded from CDN).
